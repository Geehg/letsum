# Hermes 3000 정밀 외형과 근접 구도 — 2026-10-31

첫 모델 Hermes 3000에 기존 독립 검토용 1세대 정밀 외형을 실제 필사 엔진과 연결했다. 다른 두 모델의 외형은 변경하지 않는다.

## 참고와 확인 범위

- 제조사 Paillard 설명서(원본 스캔): https://site.xavier.edu/polt/typewriters/Hermes3000.pdf — 구성도에 종이 누름대(23), 고무 롤러(17/29), 카드 홀더(20/24), 활자 가이드(22), 리본 캐리어(39), 리본 선택기(40)를 명시. 배열에 따른 TAB/Backspace 위치 차이도 명시.
- 소유자 Stephen Hanafin의 1962 #3138796 사진: https://typewriterdatabase.com/1962-hermes-3000.17953.typewriter — 이번에도 키보드 사진을 직접 열어 6개 상단 조작키, 숫자행, 키캡과 외장 색을 대조했다. 사진은 관찰용이며 사이트에 복제하지 않았다.
- 제조사 설명서 추가 스캔: https://www.munk.org/projects/Hermes_3000_Manual/
- YouTube 실기 사용 안내: https://www.youtube.com/watch?v=g80aCw_x7YE — 검색에서 종이 삽입(03:00), 리본 반전(05:20) 챕터를 확인했다. 이번 도구에서 영상 본문 프레임/자막은 확보하지 못했으므로 영상을 정밀 동작 측정의 근거로 삼지 않는다.
- 기존 형상 제작 근거와 한계: HERMES_REFERENCE_BUILD.md.

## 구현

- `typing-hermes-reference.js`: 54키 외형, 곡면 외장, 누름대의 마진 표시, 고무 롤러, 투명 카드 홀더, 리본·활자봉·리턴 레버를 기존 입력 드라이버에 연결. 실물 키 배열은 외형이며 한글 필사와 현대 키보드 입력은 기존 엔진으로 처리한다.
- 카메라는 전체/근접 버튼으로 변경하고 로컬 저장. Hermes에서만 표시한다. 원본 입력 요소나 기록을 재생성하지 않는다.
- 근접 카메라의 투영값으로 HTML 종이와 글자 크기를 재계산한다. 모바일에서는 확대한 종이가 레이아웃 viewport까지 확장하지 않도록 stage overflow를 clip한다.
- 정밀 외형 GLB는 기존 약 13 MB 파일을 재사용한다. 최초 다운로드·브라우저 GPU 메모리 부담은 증가한다. 기존 숨긴 기구는 입력 동작 드라이버로 유지한다. 서버 렌더링이나 사용자별 서버 연산은 추가하지 않는다. GPU 성능/FPS 보장은 측정하지 않았다.
- 실측 CAD 복제가 아니다. 형상, 재질, 축 위치와 동작 시간은 시각적 근사다. 모든 이중 키 각인, 내부 전달기구, 국가별 배열까지 복제하지 않았다. 기존 생성 엠블럼도 공식 스캔이 아니다.

## 검증

- `TYPEBOOK_CLOSEUP=1`로 `tools/check_typing_paper_browser.cjs` 실행: 데스크톱/모바일 각 390자, 실제 줄 전환과 벨·리턴 이벤트 비교, 다음 글자 노출 및 종이 위치 튐 검사.
- 기존 입력 상호작용 테스트를 Hermes 근접으로 실행: 실제 Enter/Backspace, 한글 삽입 및 composition 이벤트, 구도 전환 4회 입력 보존, 화면 크기 변경, 종이 모드 변경, 다음 페이지 초기화.
- 기존 전체 구도의 세 모델 회귀 검사와 프로젝트 validator 실행. 오류 0, 기존 경고 272.
