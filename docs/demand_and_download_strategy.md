# 실수요·사용성 분석과 다운로드 전략

작성일 2026-10-11 · 근거: Similarweb(눈누, 2026-09), Google·네이버 자동완성(2026-10-11), 배포처 링크 실측, 라이선스 원문 조사

## 1. 유사 사이트에서 사용자가 실제로 쓰는 것

### 눈누 (Similarweb 추정, 2026-09)
- 3개월 95만 방문(월 ~32만), 이탈률 42%, **방문당 4.9페이지, 체류 3분 22초** → 한 번 와서 폰트 페이지를 여러 장 넘겨 보고 나간다. "폰트 상세 페이지"가 소비 단위.
- 유입의 **76%가 검색**. 상위 키워드: 눈누, 눈누폰트, **프리텐다드, pretendard**, 폰트 → 브랜드 검색 다음으로 **특정 폰트 이름**이 관문이다. 폰트별 페이지의 SEO가 트래픽의 핵심.
- 경쟁 친화도: 산돌구름 100%, Google Fonts 92%, DaFont 90%, Fontspring 85% → 같은 사용자가 국내·해외 폰트 사이트를 오가며 쓴다.
- 눈누가 최근 추가한 기능(뉴스레터): **굵기 수 필터**(크기 바 옆 슬라이더) → 다굵기 패밀리 수요.

### 검색 자동완성이 보여주는 실수요 (Google·네이버)
| 의도 | 실제 검색어 | 시사점 |
|---|---|---|
| 받기 | 무료폰트 다운로드 사이트, 무료 폰트 ttf, 폰트 다운로드 무료 | 사이트 선택 기준 1위는 "바로 받을 수 있나". **TTF**를 콕 집어 찾는다(웹폰트 WOFF는 설치 불가) |
| 적용 | 폰트 다운로드 **적용**, 폰트 다운로드 후 **PPT 적용**, 폰트 설치 후 적용 **안됨**, 설치했는데 **안보임**, 설치 위치/폴더 | 다운로드 다음 단계에서 막힌다. 설치·PPT·한글(HWP) 적용 안내가 검색 수요 그 자체 |
| 안심 | 폰트 저작권 **확인 사이트**, 위반 사례, **합의금**, 내용증명, 협박 | 라이선스 공포가 큰 동기. "확인했다는 근거"를 남길 수 있어야 한다 |
| 기기 | 아이폰 무료 폰트, 갤럭시 무료폰트 | 모바일 기기 적용 수요가 별도로 큼 |
| 스타일 | 손글씨 폰트, 상업용 무료 폰트 **영어·필기체·고딕**, 한자 상업용 무료 폰트 | 영문 전용·한자 수요도 있음(한글 사이트의 빈 자리) |
| 특정 폰트 | 눈누 프리텐다드, 네이버 폰트 다운로드, 온글잎 폰트 | 폰트명+다운로드 페이지가 유입구 |

### 해외 사이트의 사용 패턴(공개 자료·관찰)
- Google Fonts: 사용자가 가장 원한 것은 "더 많은 폰트"와 **쉬운 사용**(2011 UX 조사). Analytics 페이지로 사용량을 공개.
- Fontshare: 가입·메일 수집 없이 **즉시 다운로드**가 평가의 핵심. 재배포 금지라 "fontshare.com에서 받게 하라"는 조건.
- DaFont: 8만 종이지만 라이선스가 제각각 → 큰 카탈로그보다 "쓸 수 있는지"가 문제.
- 타입 파운드리(F37·Commercial Type): 테스터의 **정밀 조작**(크기·행간·자간 값 표시), 폰트 **핀 고정 비교**.

## 2. 구현에 반영한 우선순위

1. **다운로드가 첫 번째 행동** → 상세 모달 상단에 "받기" 패널. ZIP 바로 받기(원 배포처 파일) / 원 배포처 페이지 / 웹폰트 코드.
2. **설치·적용 안내를 다운로드 옆에** → Windows·Mac 설치, PPT·한글 적용(재시작, 파일명≠글꼴명, 글꼴 포함 저장), 아이폰·갤럭시 안내.
3. **라이선스 증빙 저장** → 폰트명·저작권자·라이선스·사용 범위·검수일·원 배포처 URL·저장 시각을 텍스트 파일로 내려받아 분쟁 대비 근거로 보관.
4. **폰트별 정적 페이지**(`font/<id>.html`) → "폰트명 다운로드" 검색 유입구. 제목·설명·JSON-LD 포함, 열면 작업대 모달로 연결.
5. 링크 상태 주간 점검 → 끊긴 링크는 자동으로 "원 배포처 페이지" 안내로 전환.

## 3. 가장 빨리 받게 하는 방법 — 다운로드 전략

### 링크 실측 (2026-10-11)
| 경로 | 결과 | 비고 |
|---|---|---|
| `fonts.google.com/download?family=X` | 200이지만 **HTML 페이지**(193KB) — 브라우저에서 열면 JS가 ZIP을 묶어 자동 다운로드 시작 | 사용자 링크로는 동작(클릭 1회 + Google Fonts 화면 잠깐). 스크립트로 파일을 받을 수는 없음 |
| `fonts.google.com/download/list?family=X` | 200, 파일별 gstatic URL + OFL.txt 본문 JSON | **보관용 ZIP은 이 목록으로 직접 묶는다**(`tools/archive_files.py`: TTF + OFL.txt + SOURCE.txt). 고운바탕 3.3MB 확인 |
| GitHub Releases 자산(Pretendard 등) | 302 → 서명 URL, 200 | 안정. 브라우저 이동으로 바로 저장 |
| `github.com/google/fonts/raw/...` | 200 | 개별 TTF 직접 |
| 네이버 한글 캠페인 다운로드 경로 | 404 | 배포처 페이지가 바뀜 → 페이지 링크 + 주간 점검 필요 |

### 3단계 전략
| 단계 | 대상 | 방법 | 사용자 체감 |
|---|---|---|---|
| **A. 자체 미러(최고 속도)** | OFL·Apache·공공누리 1유형처럼 **재배포가 명시적으로 허용**된 폰트 | 승인된 원본 ZIP(라이선스 파일 포함)을 **GitHub Releases**(공개 저장소 `letsum-mirror`, 무료·카드 불필요·주소 고정)에 올려 제공. 원본 해시를 `tools/state/archive.json`에 기록. ※ Cloudflare R2는 무료 한도(10GB)가 있지만 **계정에 카드 연결 구독을 추가해야 해서** 비용 0원 원칙상 채택하지 않음 | 클릭 1회, 배포처가 사라져도 유지 |
| **B. 원 배포처 직링크(기본)** | 재배포 조건이 불명확하거나 금지(구 카카오 OTF 등) | 배포처의 ZIP/릴리스 URL로 바로 이동. 주간 상태 점검으로 끊김 감지 | 클릭 1회, 배포처 속도 |
| **C. 배포처 페이지 안내(대체)** | 로그인·앱 설치가 필요한 곳(산돌구름 즉시사용), 링크 불안정 | 페이지 링크 + "받는 방법" 한 줄 안내 | 클릭 2~3회 |

- 어느 단계든 **라이선스 알약과 요약을 버튼 옆에** 둔다("상업용 OK · 임베딩 ✓ · BI/CI ✓").
- 재배포 판단 기준: OFL(단독 판매 금지·라이선스 동봉), 공공누리 1유형(출처 표시), 배민·티몬처럼 "수정·재배포 가능, 유료 판매 금지" 명시 원문. 자료가 엇갈리는 폰트(티몬 수정 여부)는 B로.
- **NAS에서 직접 ZIP을 내보내지 않는다**: Cloudflare 무료 CDN은 자체 원본의 대용량 파일 서빙을 제한(2023 약관). NAS는 보관·검수용(`tools/archive/`).
- 설치 가능한 형식(TTF/OTF)을 먼저, 웹용(WOFF2)은 "설치 불가" 표기와 함께 분리.

### 다음 단계
1. `tools/watch_sources.py`에 링크 상태 점검 포함(구현) → `html/data/links.json`.
2. `tools/archive_files.py`(구현): 승인 레코드의 원본을 받아 ZIP·해시 기록. 업로드 대상은 GitHub Releases(`gh release upload`)로 전환 예정. 사이트는 `dl.mirror` URL을 우선.
3. 폰트별 페이지 빌드를 배포 전 단계에 포함(`tools/build_pages.py`).
4. 영문 전용·한자 폰트 섹션 검토(검색 수요 있음, 한글 사이트의 빈 자리).
