# Olympia SM3 — 확인 근거와 웹 모델 범위

2026-10-26. 사용자 첨부의 정면·측면·상면·부품 사진을 관찰하고, Olympia Werke AG 발행 SM3 사용설명서의 사진·번호 도해·작동 설명을 대조했다. 첨부 시트의 연도·인물·치수 문구 자체를 사실 근거로 삼지 않았다.

## 확인 자료

- 제조사 발행 **Olympia SM3 Operating Instructions**, 8쪽을 4개 펼침면으로 스캔: https://www.londontypewriters.co.uk/wp-content/uploads/2022/01/London-Typewriters-Olympia-SM3-instruction-manual-English.pdf
- 같은 설명서의 다른 보관처: https://site.xavier.edu/polt/typewriters/OlympiaSM3.pdf
- 사용자 제공 사진 2장: olive-gray 본체, 녹색 키, 크롬 테두리와 오른쪽 Olympia 필기체 마크의 외형 참조. 조명·화이트밸런스가 불명인 사진이므로 공장 도료의 측색값으로 취급하지 않는다.

## 확인 사실과 반영

| 부분 | 근거 | 구현 |
| --- | --- | --- |
| Shift | 제조사 PDF 첫 펼침면: Shift 23을 누르면 캐리지가 상승 | SM3에서 바스켓은 고정, 캐리지·플래튼·종이가 함께 상승. 양쪽 Shift 중 하나만 놓아도 다른 쪽이 눌려 있으면 유지 |
| 몸체·상판 | 사용자 정면/측면: 높은 둥근 어깨, 넓은 상판, 안쪽으로 들어온 두 날개와 활자부 개구부 | 전용 외곽·상판 메시, 닫힌 앞쪽 마감, 상판과 하부의 가는 금속 이음선 |
| 표면·키 | 사진: 거친 올리브 그레이 표면, 짙은 녹색 키와 밝은 각인, 둥근 사각 윗면과 두꺼운 옆면 | 반복 미세 범프, 무광 몸체, 별도 키캡 스커트·오목한 윗면·작은 테두리 반사 |
| 종이 지지대 | PDF 두 번째 펼침면 도해: 7번 paper support | 이전 모델의 두 지지대를 숨기고 단일 접이식 지지대 형상으로 변경. 캐리지와 함께 이동 |
| 플래튼·레버 | 도해의 15번 노브, 18번 줄간격 레버; 사진의 홈 있는 노브와 곡선 금속 손잡이 | 녹색 홈 노브·금속 테두리, 별도 곡선 리턴 레버, 기존 종이 이송 및 회전 연결 |
| 활자부 | 사용자 확대 사진과 PDF 마지막 펼침면: 중앙 가이드, 방사형 세그먼트, 두 리본 스풀 | 중앙 반원형 금속 가이드와 고정 세그먼트 칸막이를 별도 표현. 움직이는 타입바는 기존 입력 리그 사용 |
| 리본 | PDF 두 번째 펼침면: black/red/stencil 선택, 마지막 펼침면 교체 도해 | 오른쪽 선택부에 검정·흰색·빨강 표시. 사용자가 앞서 지정한 실제 표시 리본은 검정 유지 |
| 탭 | PDF 세 번째 펼침면: 뒤쪽에서 수동 설치하는 tab stop | SM4의 전면 탭 설정 장치를 SM3 사실로 혼합하지 않음. 내부·후면 조작 전체를 가상 작동품으로 추가하지 않음 |
| 마진·벨 | 설명서: 마진 스톱, 마진 도달 8칸 전 벨 | 기존 필사 화면의 원문 행 기준 벨 유지. 비례폭 한글 입력에서 실물의 8칸 거리까지 복제했다고 주장하지 않음 |

## 의도적인 웹 적용 범위

실물 측정 CAD가 아니라 사진의 가시 외형과 설명서로 확인한 동작 원리를 반영한 웹 모델이다. 제조사 도면에서 확보하지 못한 외장 곡률, 금속 두께, 링크 길이, 표면 거칠기, 이동량·시간은 제작값이며 실측값으로 제시하지 않는다. 숨겨진 내부 기구를 검증된 구조처럼 새로 만들어 넣지 않았다.

사용자 요청으로 정리한 **61키 컴퓨터 입력 배열**을 유지한다. 원형 SM3의 키 수·지역별 배열을 복제한 것이 아니다. 전체를 가로로 강제 늘이지 않고 외장과 키캡을 별도로 제작했다. A4 원문 겹침, 한글 IME, 글자 수 표시창, 검정 리본, 테이블보와 음량 설정은 기존 서비스 요구다.

키·47개 타입바·리본·캐리지의 기본 연결은 공유 리그를 사용한다. SM3의 캐리지 Shift는 분기 구현했다. 필기체 Olympia 마크는 사진을 보며 그린 경로이며 원본 로고 도면이 아니다. 소리는 기존 출처 표시된 실제 녹음을 공유하며 SM3 전용 원음이라고 표시하지 않는다.

## 검증

`tools/check_typing_hermes.mjs`를 기본 / `--lettera` / `--olympia`로 실행한다. 키 입력, 한글 조합, 타입바 타격점, 캐리지·종이 이송, 닫힌 외곽·키캡 표면, 모델 왕복 전환 시 필사 보존 및 중복 이벤트 제거, WebGL 실패 복구를 검사한다. SM3에는 캐리지 상승·바스켓 고정·HTML 종이와 깊이 마스크 동기화·양쪽 Shift 유지 검사를 추가했다.
