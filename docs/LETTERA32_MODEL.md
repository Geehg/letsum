# Olivetti Lettera 32 — 확인 근거와 웹 모델 범위

2026-10-26. 사용자가 제공한 두 장의 이미지에서 모델명·표면 형상을 관찰하고 제조사 발행 자료와 대조했다. 생성형 참조 시트의 문구 자체를 역사적 사실의 출처로 사용하지 않았다.

## 1차 자료

- British Olivetti Ltd., Lettera 32 영문 안내서, 하단 인쇄 표시 3-65: https://site.xavier.edu/polt/typewriters/OlivettiLettera32_ManualEN.pdf
- SFMOMA 소장품 2004.182.A-B: https://www.sfmoma.org/artwork/2004.182.A-B/ — Marcello Nizzoli, Olivetti 제조, 1963, 금속·플라스틱·도장. 소장품 실측값은 10.4 × 34.5 × 35.1 cm로 제조사 안내 수치와 다르므로 둘을 혼합하지 않는다.

## 재구성 범위

이 결과는 실물 스캔이나 제작 도면에서 얻은 CAD 복제품이 아니다. 사진에서 확인 가능한 외형을 코드로 구축한 **61키 필사 인터페이스**다. 원형 키 배열·키 수와 다르며, 사용자 요청에 따른 Ctrl/Alt/Win 등 컴퓨터 입력 키를 유지한다. 사진의 기능키를 동작 불가능한 장식 키로 추가하지 않았다.

키·타입바·캐리지·종이의 연결은 기존 검증된 웹 애니메이션 리그를 공유한다. 따라서 링크 길이, 키 이동량, 작동 시간, 카메라 투영, 상판 곡률, 표면 거칠기 값은 웹 연출용 제작값이다. 실제 Lettera 기구학을 측정·복제했다고 주장하지 않는다. 사진만으로 알 수 없는 내부 구조를 새로 사실처럼 만들어 넣지 않았다.

연청색은 사용자 이미지와 제조사 사진의 시각적 참조이며 공장 도료의 측색값은 확보하지 않았다. 효과음은 기존 출처 고지된 실제 녹음을 공통 사용하며 Lettera 32 전용 녹음이라고 표시하지 않는다. 검정 리본, 글자 수 창, A4 한 장 원문 겹침은 서비스의 기존 사용성 요구다.

## 파일과 검증

- `html/js/typing-lettera.js`: 자체 작성 외곽·상판·키캡·리턴 레버·눈금·명판 형상. 기존 모델을 단순 변색하거나 전체를 늘인 방식이 아님.
- `html/js/typing-hermes.js`: 공유 애니메이션, 모델 변경 시 이벤트·관찰자·GPU 자원 해제.
- `html/js/typing-3d.js`: 설정 선택과 localStorage 저장, 몰입 모드에서 두 모델 지원.
- `tools/check_typing_hermes.mjs`와 `--lettera`: 키 입력·IME·타입바·리본·캐리지·종이·닫힌 표면·오류 시 기본 입력 복귀 검사.

## 2026-10-26 — 마감·도장 광택 보강

사용자 추가 확대 화면에서 키 영역 앞 모서리의 찢어진 듯한 면, 도장의 늘어진 얼룩, 높고 무광인 키, 약한 상판 접힘을 관찰했다.

- 베젤의 원인은 둘레 길이로 균등 샘플링한 외곽/내곽 링의 대응 모서리가 달라진 연결이었다. 직선·곡선 구간끼리 같은 수의 정점을 연결하도록 변경했다. 키 바닥과 외곽의 겹침을 줄이고 후면 캐리지 통로도 확보했다.
- 기존 공유 재질 보정이 Lettera의 clearcoat/roughness를 무광 값으로 덮어쓰고 있었다. Lettera 도장 재질을 별도로 보존하고, 미세 bump만 적용한다. UV는 상판 평면/몸체 둘레·높이 기준으로 정리해 길게 늘어진 표면 무늬를 제거했다.
- 상판은 완만한 좌우 크라운, 넓은 전면 경사, 평탄한 윗면으로 넘어가는 짧은 곡면 전환을 구성했다. 삼각형별 법선 재계산 대신 원래 모서리 법선에 변형의 역전치 관계를 적용해 대각선 반사 패치를 줄였다.
- 키는 낮은 옆면·둥근 사각 테두리·오목한 중앙을 다시 만들고, 검정 수지의 반사와 밝은 각인을 분리했다. 키 아래 링크의 과한 밝기를 낮췄다. 기존 61키 입력 배열은 유지한다.
- 연속 상판 이음새, 앞쪽 마감면, 명판의 표면 높이를 재조정했다. 재질 수치·곡률은 사진을 기준으로 만든 웹 표현값이며 제조사의 실측 사양이나 광택도 측정값이 아니다.
- 검사에 Lettera 전용 도장/키 광택 보존, 곡면 법선 유효성, 캐리지 좌우 이동 시 외장 간격을 추가했다.
