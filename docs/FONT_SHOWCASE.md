# 폰트 샘플 리뷰 30종

- 기존 한글 카탈로그의 pop 정렬 상위 30종. 실제 시장 순위나 방문자 좋아요 순위라는 주장은 하지 않음.
- 샘플 문구·데모 좋아요는 정적 데이터. D1 댓글·좋아요·베스트 리뷰·인기순 집계에 포함하지 않음.
- 모든 샘플에 실제 이용자 후기가 아니라는 표시. 가상의 닉네임·작성일·실사용 경험 없음.
- 이미지: 공식 출처의 일부 화면만 캡처. 실제 서비스 사용 / 공식 적용 예시 / 공식 견본을 구분.
- 확인 방법: Chrome CSS.getPlatformFontsForNode에서 실제 사용된 커스텀 글꼴과 glyphCount 확인. 이미지형 사례는 제작사 명시적 설명 확인.
- 근거와 원본 URL: tools/state/font_showcase.json. 원문 확인 불가 시 이미지 미등록.
- 재생성: node tools/build_ui_language.js 또는 node tools/build_pages.js. 생성 파일 html/js/font-showcase.js는 직접 편집하지 않음.
- 원문 및 캡처 확인일: 2026-10-29. 캡처 권리는 각 출처에 있으며 폰트 식별·비교 설명에 필요한 부분을 출처와 함께 표시.
