# LETSUM 화면 언어

2026-10-29: `letsum.app`의 화면 언어를 한국어/영어로 선택한다. `/en/`은 계속 영문 폰트 **카테고리**이며 화면 언어와 별개다. `type.letsum.app`과 관리자 화면은 이번 변경 대상이 아니다.

## 선택 순서 (2026-10-31 검색 노출 보완)

1. 현재 URL의 `?ui=ko` / `?ui=en` (명시적 선택으로 저장)
2. 사용자가 선택한 `localStorage.ls_ui_language`
3. 명시적인 선택이 없으면 항상 한국어. 국가·브라우저 언어·예전 지역 캐시는 본문과 제목을 자동 번역하지 않는다.

`GET /api/locale`의 Cloudflare 국가 판별(KR → ko, 다른 확인된 국가 → en)은 **영어 전환 추천에만** 사용한다. 국가 미확인/오류/1.5초 시간 초과 시 브라우저의 첫 번째 선호 언어를 추천 기준으로 쓴다. 영어가 추천되면 상단 `English →` 버튼을 강조한다. 사용자가 누르기 전까지 내용·제목·기본 주소는 한국어로 유지한다. 검색 로봇 식별에 따른 예외는 없다.

국가 판별 결과는 탭의 `sessionStorage.ls_ui_region`에 30분간만 보관한다. 원래 국가 코드·IP·위치 좌표는 이 API가 반환하거나 저장하지 않는다. 응답은 private/no-store이며 DB를 사용하지 않는다. 늦게 도착한 응답은 사용자의 언어 선택을 덮어쓰지 않는다. 저장소가 차단돼도 페이지 링크와 공통 검색은 `ui`를 유지한다. 저장된 수동 선택을 복원할 때도 현재 URL에 `ui`를 반영해 공유·새로고침에서 같은 화면 언어가 유지되며 기존 검색 조건과 해시는 보존한다.

## 검색엔진 기준

- 언어를 선택하지 않은 기본 주소는 어느 국가·브라우저에서도 한국어 제목·본문으로 표시한다. HTML 원문의 한국어 제목·설명·구조화 데이터·canonical은 유지한다.
- `?ui=en`은 방문자가 선택하는 영어 **화면 모드**다. 기존 canonical은 한국어 기본 주소를 가리킨다. 일부 편집 본문은 한국어로 남으므로 독립적인 영어 SEO 페이지로 표시하거나 `hreflang`을 추가하지 않는다.
- `/en/`은 영문 글꼴 카테고리이며 한국어 홈페이지의 번역 URL이 아니다. 폰트 상세·주제 페이지·영문/딩벳 카테고리 모두 같은 선택 규칙을 적용한다.
- 영어 전용 검색 노출이 필요해지면 본문·메타데이터를 완전히 번역한 독립 URL과 상호 `hreflang`을 별도로 설계한다.

## 번역 소스와 생성

- `tools/i18n/en.json`: 원문 문자열 → 영어. 변경된 원문은 기존 번역을 억지로 재사용하지 않고 원문으로 표시한다.
- `tools/i18n/runtime.js`: 언어 결정, 접근성 속성, 동적 화면 번역, 언어 전환.
- `html/css/ui-language.css`: 전환 버튼과 영어/모바일 레이아웃.
- `html/js/ui-language.js`: **생성물**. 직접 수정하지 않는다.
- `node tools/build_ui_language.js`: 번역 번들과 공개 페이지의 스크립트·스타일 참조 및 콘텐츠 해시를 갱신한다.
- `node tools/build_pages.js`: 마지막 단계에서 위 생성기를 실행하므로 상세·주제·카테고리 페이지 재생성 시 언어 기능을 유지한다.

원래 필터 키, 데이터, 폰트 이름표, 다운로드 주소, 코드, 입력 문장, 댓글 및 프로젝트 이름은 번역 값으로 바꾸지 않는다. 텍스트를 번역해도 DOM 요소·이벤트는 교체하지 않는다. `option`의 암묵적 value도 보존한다. 내부 상태를 화면의 번역된 textContent로 비교하지 않는다.

번역 범위는 공통 메뉴, 탐색·검색·필터·보기·비교, 주요 상세/다운로드/리뷰/보관함 UI, 라이선스 가이드와 등록된 라이선스 요약, 정책 페이지다. 영문 폰트의 규칙형 소개는 영어로 표시한다. 개별 폰트의 한국어 고유명·제작사·출처, 아직 번역되지 않은 편집 소개/추천 이유/주제 글, 한글 견본은 원문을 보존한다. 소개 문단은 영어 화면에서 `Original Korean text`로 표시한다. PDF 확인서는 한국어다. 문학 원문이나 이용자가 작성한 내용은 자동 번역하지 않는다.

## 확인

```sh
node tools/build_pages.js
python3 -I tools/validate.py
node tools/check_ui_language.mjs
# 로컬 html 서버를 실행한 상태에서, 설치된 Playwright 모듈 경로 지정
LETSUM_PLAYWRIGHT=/path/to/playwright LETSUM_TEST_URL=http://127.0.0.1:8879 node tools/check_ui_language.mjs
```

브라우저 검사는 한국/해외/미확인, 장애·시간 초과, 기존 지역 캐시에서도 한국어가 유지되는지, 주요 공개 페이지의 제목·설명·H1·canonical, 해외 영어 추천, 명시적/저장된 선택, 저장소 차단, 늦은 응답, 양방향 전환, 동적 요소, 검색·분류·대안 필터, 미리보기/댓글 원문 보존, 카테고리 이동, 상세 라이선스/배포처 링크, 모바일 필터를 확인한다. 외장 볼륨의 `._*.js`는 JavaScript가 아니라 macOS 메타파일이며 검증 입력에 포함되면 제거 후 다시 확인한다.

최초 언어 기능 배포에는 Worker(`/api/locale`)와 정적 파일이 필요하다. 이번 검색 노출 보완은 정적 파일만 변경하며 Worker·nginx·유료 서비스 변경은 없다. API가 실패해도 기본 한국어와 수동 영어 전환은 동작한다. `?ui=en` / `?ui=ko`는 운영 화면 확인에도 쓸 수 있다. 기본 언어·국가별 추천 검사는 저장된 언어와 `ui`가 없는 새 브라우저 컨텍스트로 한다.
