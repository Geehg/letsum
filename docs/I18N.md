# LETSUM 화면 언어

2026-10-29: `letsum.app`의 화면 언어를 한국어/영어로 선택한다. `/en/`은 계속 영문 폰트 **카테고리**이며 화면 언어와 별개다. `type.letsum.app`과 관리자 화면은 이번 변경 대상이 아니다.

## 선택 순서

1. 현재 URL의 `?ui=ko` / `?ui=en` (명시적 선택으로 저장)
2. 사용자가 선택한 `localStorage.ls_ui_language`
3. `GET /api/locale`의 Cloudflare 국가 판별: KR → ko, 다른 확인된 국가 → en
4. 국가 미확인/오류/1.5초 시간 초과 → 브라우저의 첫 번째 선호 언어(ko 계열은 ko, 나머지는 en)

국가 판별 결과는 탭의 `sessionStorage.ls_ui_region`에 30분간만 보관한다. 원래 국가 코드·IP·위치 좌표는 이 API가 반환하거나 저장하지 않는다. 응답은 private/no-store이며 DB를 사용하지 않는다. 늦게 도착한 응답은 사용자의 언어 선택을 덮어쓰지 않는다. 저장소가 차단돼도 페이지 링크와 공통 검색은 `ui`를 유지한다.

## 번역 소스와 생성

- `tools/i18n/en.json`: 원문 문자열 → 영어. 변경된 원문은 기존 번역을 억지로 재사용하지 않고 원문으로 표시한다.
- `tools/i18n/runtime.js`: 언어 결정, 접근성 속성, 동적 화면 번역, 언어 전환.
- `html/css/ui-language.css`: 전환 버튼과 영어/모바일 레이아웃.
- `html/js/ui-language.js`: **생성물**. 직접 수정하지 않는다.
- `node tools/build_ui_language.js`: 번역 번들과 공개 페이지의 스크립트·스타일 참조 및 콘텐츠 해시를 갱신한다.
- `node tools/build_pages.js`: 마지막 단계에서 위 생성기를 실행하므로 상세·주제·카테고리 페이지 재생성 시 언어 기능을 유지한다.

원래 필터 키, 데이터, 폰트 이름표, 다운로드 주소, 코드, 입력 문장, 댓글 및 프로젝트 이름은 번역 값으로 바꾸지 않는다. 텍스트를 번역해도 DOM 요소·이벤트는 교체하지 않는다. `option`의 암묵적 value도 보존한다. 내부 상태를 화면의 번역된 textContent로 비교하지 않는다.

번역 범위는 공통 메뉴, 탐색·검색·필터·보기·비교, 주요 상세/다운로드/리뷰/보관함 UI, 라이선스 가이드와 등록된 라이선스 요약, 정책 페이지다. 영문 폰트의 규칙형 소개는 영어로 표시한다. 개별 폰트의 한국어 고유명·제작사·출처, 아직 번역되지 않은 편집 소개/추천 이유/주제 글, 한글 견본은 원문을 보존한다. 소개 문단은 영어 화면에서 `Original Korean text`로 표시한다. PDF 확인서는 한국어다. 문학 원문이나 이용자가 작성한 내용은 자동 번역하지 않는다.

## 확인

```sh
node tools/build_pages.js
python3 -I tools/validate.py
node tools/check_ui_language.mjs
# 로컬 html 서버를 실행한 상태에서, 설치된 Playwright 모듈 경로 지정
LETSUM_PLAYWRIGHT=/path/to/playwright LETSUM_TEST_URL=http://127.0.0.1:8879 node tools/check_ui_language.mjs
```

브라우저 검사는 한국/해외/미확인, 장애, 명시적 선택, 저장소 차단, 늦은 응답, 양방향 전환, 동적 요소, 검색·분류·대안 필터, 미리보기/댓글 원문 보존, 카테고리 이동, 상세 라이선스/배포처 링크, 모바일 필터를 확인한다. 외장 볼륨의 `._*.js`는 JavaScript가 아니라 macOS 메타파일이며 검증 입력에 포함되면 제거 후 다시 확인한다.

배포 시 Worker(`/api/locale`)와 정적 파일을 함께 반영한다. Worker가 먼저 배포되지 않아도 사이트는 브라우저 언어로 동작한다. nginx 변경이나 유료 서비스는 필요 없다. `?ui=en` / `?ui=ko`는 운영 화면 확인에도 쓸 수 있다. 국가 자동 선택 검사는 저장된 언어와 `ui`가 없는 새 브라우저 컨텍스트로 한다.

Cloudflare 근거: https://developers.cloudflare.com/workers/runtime-apis/request/#incomingrequestcfproperties
