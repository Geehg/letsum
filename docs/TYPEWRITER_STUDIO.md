# 문자로 그리는 화방

로컬 진입: `http://localhost:8777/#/studio`. 운영 경로는 `https://type.letsum.app/#/studio` (이번 구현은 아직 배포하지 않음).

## 화면과 데이터
- 헤더의 서가 옆 화방. 3종 타자기 선택 후 작업대 진입. 기존 정면 미리보기 PNG를 재사용하고 종이 이송·캐리지 좌우 이동·타건 표현을 CSS로 재생한다. 별도 3D 모델을 새로 로드하지 않는다.
- JPG/PNG/WebP, 20MB 및 60MP 제한. Blob URL로 읽고 교체 시 해제한다. 원본/변환 결과는 서버 전송·localStorage 보관하지 않는다.
- 내장 꽃병 예제는 Canvas 도형으로 직접 그린다. 외부 사진 의존 없음.
- 화방은 읽기 화면과 별도 section이며 #/studio 경로에서만 표시한다. 이동/탭 비활성화 시 재생 중단, 작업은 현재 페이지에서 유지. 새로고침 시 초기화.

## 변환
`typing-studio-core.js`: RGB 밝기와 투명 배경 합성 → 대비/주변 밝기 차이로 윤곽 강화 → 문자 획의 6×9 축소 표본과 비교. 평균 농도와 구역 내부 명암 형태 오차를 함께 최소화하고 농도 오차를 인접 구역으로 확산한다. 어두운 구역은 최대 9타까지 중첩할 수 있다. 실제 3D 깊이/객체 인식 또는 학습 모델을 사용하지 않는다.
- 80 / 120 / 160열, A4 내부 비율 및 문자 가로세로비에 맞춘 행수.
- Courier New/monospace를 사용하는 실제 브라우저 글자 표본으로 농도를 보정. 플랫폼별 폰트 래스터화 차이는 있을 수 있다.
- Worker에서 처리하여 화면 입력을 막지 않는다. 취소/이동 시 terminate. 결과 Uint8Array(문자 표본 인덱스)를 순서대로 Canvas에 그린다.
- 사진의 내용이나 구도를 이해하는 수작업 예술가의 선택을 재현하지는 않는다. 원본 대비·해상도에 따라 표현 품질이 달라진다.

## 출력
- 원본 이미지를 섞지 않은 문자 그림을 다시 그려 2480×3508 PNG로 저장.
- 동일 해상도 그림을 JPEG 0.97로 PDF에 삽입. MediaBox 595.2756×841.8898 pt, A4 세로 한 페이지. 문자 선택 가능한 벡터 PDF가 아닌 이미지 PDF.
- 인쇄: `ts-art` named page로 A4/0 margin. 기존 필사 인쇄의 페이지 여백에 영향 없음.
- Web Share 파일 공유 지원 시 PNG 전달, 미지원 시 PNG 다운로드 안내. 자동으로 외부 수신자에게 보내지 않는다.

## 확인
- `node tools/check_typing_studio.mjs`: 흰색/투명 픽셀, 명암 순서, 중첩 OFF, 재현성, 리본 농도, 좌우 형태 보존, DOM ID 중복 검사.
- 브라우저: 3종 모델 선택/전환, 내장 예제와 첨부 PNG 업로드, 160열 처리, 재생/일시정지/서가 왕복, 콘솔 오류 없음, 390px 가로 넘침 없음.
- PNG 실제 다운로드 및 2480×3508 확인. PDF 실제 다운로드, pdfinfo로 A4 한 페이지 확인, 렌더 육안 확인.
- OS 인쇄와 공유 수신처 선택은 사용자가 진행. 네이티브 공유 미지원 환경에는 저장 대안 제공.

### 타건 재생 보정 (2026-10-28)
- 초당 1,800칸 일괄 렌더링을 제거. 기본 20타/초(8·20·45 선택), 프레임당 최대 한 번 타건.
- 중첩 문자를 각 타건으로 분리하고 해당 칸이 끝날 때만 다음 위치로 이동.
- 줄 끝 정지 → 오른쪽 캐리지 복귀 → 한 줄 종이 이송 → 재개 순서. 연속 스캔선/무한 진동 제거.
- 바로 완성은 부분 중첩 칸을 포함해 다시 렌더링하여 저장본과 일치시킴.
- `node tools/check_typing_studio_motion.cjs`: 중첩 순서, 느린 프레임 누적 방지, 줄 끝 정지/복귀/이송, 공백 검증.
- 로컬 반영이며 운영 배포 전.

### 부품별 3D 구동 (2026-10-28)
- `typing-studio-machine.js`: 세 reference GLB의 실제 분리 노드를 로드. PNG 프리뷰는 로딩 전 표시만 사용.
- CanvasTexture 용지를 Carriage 자식으로 배치해 롤러·노브·레버와 함께 이동. 롤러 아래 용지는 clipping plane으로 가림.
- 문자 이벤트 → 키 누름/타입바와 슬러그 회전/리본 가이드 및 리본 중앙 상승. 줄 복귀 → 레버 회전, 줄 이송 → 플래튼·노브 회전.
- 별도 WebGL 인스턴스 사용, 모델 교체 시 이전 geometry/material/texture 해제, 로딩 중 재생 차단, context loss 안내.
- 참고 모델은 기존 사진 기반 근사 모델이며 부품 동작도 시각적 재현. 다운로드용 2D 작품 렌더링은 유지.
