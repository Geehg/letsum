## 확인 사실과 제작값의 경계

- 세대·개체·배열·가시 부품 관계는 위 사진 및 설명서에서 관찰했다.
- 모든 좌표, 곡률 반경, 두께, 거칠기·색·금속성 수치는 사진 외관을 맞추기 위한 **제작값**이다. 실측 자료나 공장 CAD 수치가 아니다. 조명·카메라 영향을 제거한 측색은 하지 않았다.
- 사진에 보이지 않는 내부 전달 기구, 정확한 나사 규격·홈 개수는 복제했다고 주장하지 않는다. 바스켓의 금속 살은 외관을 위한 분할이다.
- 키의 주 문자·배열을 구현했다. 모든 국가별 이중 각인과 전용 활자까지 완전 복제하지 않았다.
- 기존 생성 Hermes 엠블럼 PNG를 재사용하며, 공식 로고 원본 스캔이라고 표기하지 않는다.
- Blender 원본은 편집 가능한 곡선·모디파이어를 보존한다. 웹 GLB에는 변환된 메시와 이미지 기반 normal 맵을 포함한다.
- 검토 화면의 키 누름은 형상 확인용이다. 필사 기록, 종이 이송 및 전체 기구 연동은 기존 운영 앱에서 계속 제공한다.

## 재생성

공식 Blender 4.5 LTS(이 작업에서는 4.5.15 Apple Silicon)로 실행:

```sh
blender --background --factory-startup --python tools/modeling/build_hermes_reference.py -- --output /path/to/output
```

결과: `.blend`, `.glb`, Cycles 렌더 PNG, normal PNG, `manifest.json`. 같은 모델을 여러 각도에서 렌더링해 웹뷰와 함께 확인한다. 원본 사진과 렌더의 조명 차이를 형상 차이로 취급하지 않는다.

## 재질·조명 보강 — 2026-10-27

- 도장·키 수지·니켈 도금에 독립적인 미세 roughness 맵을 내장했다. 도장 normal 0.36 / 키 0.09이며 Mapping 노드의 5배 반복을 glTF KHR_texture_transform으로 보존한다. 흠집·오염을 사실로 추정해 그려 넣지는 않았다. 색·거칠기·코팅 강도는 여전히 실측값이 아닌 외관 조정값이다.
- 웹 환경 반사는 검은 스튜디오에 큰 창과 좁은 띠 광원을 분리했다. 상판·어깨·키 가장자리를 따라 반사가 움직인다. 니켈 부품에는 더 어두운 은색과 높은 반사 대비를 적용했다.
- 직접 그림자는 VSM으로 부드럽게 처리하고, 바닥에서 모델의 실제 하부 깊이를 한 번 렌더링해 두 차례 분리 블러한 접촉 그림자를 합성한다. 고정된 바닥 접촉 그림자로, 내부 전체의 광선 추적 AO나 동적 전역 조명은 아니다. 정지 상태에서 렌더를 반복하지 않는다.
- Blender 원본·GLB·Cycles 렌더를 함께 재생성했다. 현재 독립 검토 페이지와 로컬 산출물에만 반영하며 기존 운영 앱 교체·배포는 하지 않았다.

## 캐리지 리턴 레버 재제작 — 2026-10-27

- 기존 일정 굵기 직선 3구간과 별도 수평 손잡이를 제거했다. 기준 개체의 정면·좌측 사진을 대조해 상승하는 몸통, 부드러운 정점, 아래로 내려가는 넓은 손잡이를 하나의 닫힌 연속 메시로 구성했다. 목 부분에서 단면 폭·두께와 면 방향이 이어지도록 했다. 측면에서도 손잡이의 넓은 면이 보이도록 비틀림을 반영했다.
- 캐리지 아래에 `Carriage_return_assembly`를 두고 보이는 지지대·연결 틈·체결 머리를 분리했다. 사진에 보이지 않는 스프링·기어·정확한 회전축 작동까지 재현했다는 의미는 아니다. 각도·단면 치수는 사진 기반 제작값으로 실측 수치가 아니다.
- 측면 버튼은 레버가 있는 좌측을 보도록 변경했다. 브라우저에서 정면·좌측·사선으로 교차 검토한다. 기존 타건·재질은 유지하며 독립 검토본에만 적용한다.

## 필사 화면 레버 적용

`export_hermes_lever.py --blend PATH --output PATH`를 Blender로 실행하면 재제작 레버 부품만 GLB로 추출한다. 재질은 필사 화면의 기존 니켈을 공유하며 독립 검토본 전체를 교체하지 않는다. `typing-hermes.js`는 Hermes에서만 부품을 로드하고 기존 Return_Lever 애니메이션 피벗에 붙인다. 기준 앵커 (-0.168,0.174,-0.130)를 원점으로 맞추고 표시 배율 1.10을 적용한다. 이전 레버 두 메시는 숨긴다. Lettera/Olympia 경로는 기존 자산과 형상을 유지한다. 로딩 실패·시간 초과·모드 변경 시 추가 부품도 기존 자원 정리 경로를 따른다.
