# 상판·연결부 형상 보강 — 2026-10-27

## 확인한 원인

1. Hermes와 Lettera의 개구부 뒤쪽은 외곽과의 간격이 각각 약 0.004/0.003 장면 단위였으나 양쪽 베벨 폭 합은 0.005/0.0044였다. 닫힌 위상 검사만으로는 이런 겹침을 걸러내지 못했다.
2. Lettera/Olympia는 캐리지 이동 여유를 만들기 위해 상판 뒤쪽을 넓게 낮추었다. 이 변형이 안쪽 날개까지 이어져 움푹 내려앉은 모양이 됐다.
3. 실제 움직이는 47개 타이프바 위에 긴 장식용 방사형 살을 별도로 추가해, 중복된 금속 팬과 떠 있는 부품처럼 보였다.
4. 캐리지 양끝 연결부가 단순한 블록이며 용지 가이드 가장자리는 투명 본체와 다른 변환을 받았다.
5. VSM 그림자에서 도장면과 투명 로고 주변에 검은 점무늬/번짐이 생겼다. PCF 소프트 그림자로 변경 후 같은 카메라에서 없어지는 것을 확인했다.

## 수정

- 세 모델 개구부의 과한 베벨을 줄이고 별도의 얇고 닫힌 하향 플랜지를 추가했다. Olympia 안쪽 날개 끝을 대칭의 둥근 앞쪽 곡선으로 다시 구성했다.
- Lettera/Olympia 상판의 높이·뒤쪽 여유 구간을 분리 조정했다. Hermes는 앞쪽 덮개 높이를 보존하면서 뒤쪽 높이와 앞 개구부 곡선을 조정했다.
- 긴 장식용 살을 짧은 외곽 세그먼트로 교체하고, 스풀 플랜지·허브·중앙 프레스 금속 가이드·좁은 포크 마감을 보강했다. 움직이는 활자봉과 입력 연결은 유지했다.
- 캐리지 끝판을 베벨 처리한 축 구멍이 있는 판으로 바꾸고 별도의 베어링 칼라와 체결 나사/슬롯을 추가했다.
- 용지 가이드의 테두리에도 본체와 같은 좌표 변환·폭 연장을 적용했다.
- Olympia 도장 요철을 낮추고 키캡 높이·둥근 모서리·반사를 조정했다. 내부 도장면, 검게 처리된 금속, 가공 금속, 연마 모서리를 구별했다.
- 생성한 투명 로고와 기존 입력·이송·캐리지 피벗을 유지했다.

## 검증과 범위

닫힌 메시 검사에 더해 개구부 내부를 광선으로 샘플링하여 불필요한 캡·베벨 겹침이 없는지 검사한다. 캐리지 전체 이동 범위의 여유, 키 입력·IME·종이 이송·모델 전환·WebGL 실패 복구를 세 모델에서 검사한다. 브라우저 정면·상단·사선 확대와 실제 입력 화면을 확인한다.

이는 제공된 다각도 참고 이미지의 가시 형태를 바탕으로 한 웹용 재구성이다. 실측 CAD/사진측량 복제는 아니며, 기존 61키 웹 배열과 사용자 요청의 본체 축소·용지 독립 배치는 유지한다. 원본과 정확한 치수 일치나 사진 수준의 동일성을 주장하지 않는다. 원격 push/운영 배포는 이번 작업에 포함해 실행하지 않았다.

최종 확대 검토에서 리본의 기존 대각 경로가 개구부를 가로지르는 검은 쐐기처럼 보이는 것을 확인했다. 스풀 가장자리에서 뒤쪽 가이드로 이어지도록 리본 좌표를 수정하고, 가운데 상승 동작은 기존 가중치와 함께 유지했다. 내부 플랜지는 외장 원본 재질을 그대로 복제할 때 너무 밝아지므로, 모델별 내부 도장색을 별도로 지정했다.
