## 검토 중 발견하여 수정한 항목

1. 공식 다운로드 안내만 있고 파일 형식 표기가 없을 수 있어 `page-listed + listed_formats:[]`를 허용했습니다.
2. `catalog.updated_at`을 출처 확인일로 잘못 표시하지 않도록 **데이터 갱신일**로 수정했습니다.
3. 검색 결과만 확인한 근거와 실제 페이지 확인 배지를 구분했습니다.
4. 보관함 카테고리 숫자를 보관된 공개 항목 기준으로 바꿨습니다. draft·archived·미존재 북마크는 제외합니다.
5. 다운로드 클릭만으로 완료를 단정하지 않고 **요청**과 **요청 실패**를 구분했습니다.
6. 재렌더 후 키보드 포커스, 같은 URL에서 초기화, 보관 해제 후 초점 이동을 보완했습니다.
7. 정적 fallback에도 skip 링크 대상을 넣었습니다.
8. 작은 보조 텍스트 색을 진하게 조정했습니다. 일부 대상 색상 조합의 계산 대비는 5.64~6.68:1이며, 실제 화면 전체 접근성 감사 완료를 뜻하지는 않습니다.
9. 의미 있는 편집은 검수 정보와 기존 `current` 상태를 무효화합니다. 메모만 바꾸는 경우는 구분합니다.

## 남은 구현

실제 브라우저 검수, 기존 LETSUM 저장소 이식, 운영 DB·인증·권한·게시 경로, 제보 접수 서버, 필요 시 사용자 계정 동기화, 현행·이미지 사용 근거 확인, 실제 운영 URL·SEO·배포 검증입니다.

`docs/CODEX_HANDOFF.md`에 작업 ID와 완료 기준을 정리했습니다. 이 항목들은 구현·검증 완료로 보고하지 않습니다.

## 실행 환경과 드라이버

Node.js **24.22.1**, npm **11.9.0**, Linux에서 작성·검사했습니다. package.json의 지원 최소 버전은 Node **22**입니다. 외부 npm 패키지, DB 엔진, 전용 드라이버는 필요하지 않습니다. 운영 DB 설계안은 아직 특정 드라이버나 제품을 선택하지 않았습니다.

## 자료 전달 검증

배포 파일의 실제 바이트 수·SHA-256과 내부 파일 목록은 최상위 `FILE_MANIFEST.json`, `FILE_LIST.txt`, `SHA256SUMS.txt`에 기록합니다. manifest 자체를 자신의 해시에 포함하지 않습니다. 최종 배포 ZIP은 CRC와 각 멤버의 해시를 검사하며, 별도 전달 파일은 저장 후 다시 받은 바이트와 대조합니다.
