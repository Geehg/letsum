한글 웹폰트 서브셋 생성기

한글 폰트는 11,172자를 통째로 받으면 웹에서 무겁습니다.
아래에 실제 쓸 문장을 입력하면, 사용하는 글자만 내려받는 CSS를 만들어 드립니다.
Google Fonts의 unicode-range 분할 방식을 그대로 활용합니다.


    
    
생성된 CSS를 사이트의 <style>에 붙여넣으면, 브라우저가 필요한 분할만 내려받습니다. 폰트 파일 자체는 원 배포처(CDN)에서 제공됩니다.

  


  

    
어떻게 동작하나요?

    
    
      
  1. 입력 문장에서 중복을 제외한 유니코드 문자 목록을 추출합니다.
    2. 
      
  2. Google Fonts CSS에서 해당 폰트의 분할(unicode-range) 정보를 가져옵니다.
    3. 
      
  3. 입력 문장에 실제로 필요한 분할만 골라 @font-face CSS로 묶어 드립니다.
    4. 
      
  4. 분할 정보를 가져오지 못하면, 직접 URL을 붙여넣는 수동 템플릿을 제공합니다.
    5.
