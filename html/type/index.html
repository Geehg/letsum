필사독서 안내

  • 저작권 — 서가의 작품은 저작자 사망 후 70년이 지나 저작권 보호기간이 끝난 글입니다. 한국 작품은 위키문헌, 영어 고전은 Project Gutenberg의 공개 원문을 가져왔습니다(각 작품의 '출처'에서 원문 확인). 번역본은 넣지 않았습니다. 한자 병기는 빼고 한자는 한글 독음으로 바꿨으며 옛 맞춤법은 그대로 두었습니다. '님의 침묵'은 위키문헌의 현대어 대조본(CC BY-SA 4.0)입니다.
  • 입력 — 한글은 두벌식 자판 기준입니다. “ ” ‘ ’ 「 」 · ― 같은 문장부호는 키보드의 " ' . - 로 쳐도 맞게 처리합니다. 원문의 ↵ 자리(시의 줄 끝, 산문의 문단 끝)에서 Enter를 칩니다.
  • 기록 — 진행·타수·정확도·연속 필사일은 이 브라우저에만 저장되고 서버로 보내지 않습니다. 브라우저 데이터를 지우면 기록도 사라집니다.
  • 내 글 가져오기 — TXT·MD·EPUB(DRM 없는 파일, 10MB 이하) 또는 직접 붙여 넣은 글로 필사할 수 있습니다. 파일은 내 브라우저 안에서만 읽고 어디에도 올리지 않습니다. 내가 이용 권한을 가진 글만 가져오세요.

HOW TO

필사하는 법

  1. 왼쪽 원문을 보고 오른쪽 칸에 똑같이 입력합니다. 맞은 글자·틀린 글자·다음 글자가 원문에 바로 표시됩니다.
  2. 틀리면 Backspace로 지우고 다시 쓰면 됩니다. 한 쪽 전체가 원문과 같아지는 순간 완성됩니다.
  3. ↵ 표시가 있는 곳에서 Enter를 칩니다. 산문은 문단이 바뀔 때 한 번, 시는 줄 끝마다 치고 연이 바뀌는 곳(빈 줄)에서 한 번 더 칩니다.
  4. “ ” ‘ ’ 「 」 · ― 는 키보드의 " ' . - 로 쳐도 맞습니다. 붙여 넣기는 막혀 있습니다.
  5. 원문·필사 글꼴, 글자 크기, 이 쪽 다시 쓰기·인쇄, 레트로의 타건음·용지는 오른쪽 위 ⚙ 설정에서 바꿉니다. 손글씨 글꼴로 쓰면 손으로 쓴 느낌을 볼 수 있어요.
  6. 화면 디자인은 오른쪽 위에서 고릅니다 — 몰입(밝게·어둡게: 원문과 필사만 크게), 레트로(타자기 본체·타건음·용지 선택·필사 인쇄), 책상(서재 목록과 펼친 책), 잉크(평면 활자 견본).
  7. 분당 타수는 이 쪽에서 누른 글쇠 수 기준, 정확도는 확정된 글자 기준의 참고값입니다(공인 타자 검정 수치가 아님).

그림의 재료

작은 피사체는 확대하면 더 많은 문자로 묘사할 수 있어요. 아래 흑백 미리보기에서 잘리는 범위를 확인하세요.

곡선 · 인물 · 타이핑 내용

0자 / 최대 1,000,000자

TXT·MD·DOCX·EPUB · 20MB 이하 · 최대 100만 자. 파일은 이 기기에서만 읽습니다. 한 장에 담지 못한 본문은 다음 그림에서 이어 쓸 수 있습니다. 비우면 선택한 언어의 문자를 사용합니다. 이미지의 여백은 건너뛰고, 중첩되면 본문 가독성이 낮아질 수 있습니다.

항상 흑백 변환 + 자동 레벨 보정. 밝은 영역은 글자를 찍지 않고 여백으로 남깁니다. 초록색은 사진의 색 차이로 찾은 인물 범위입니다. 가장자리에서는 곡선과 가로 타이핑이 섞입니다. 비슷한 색의 배경이 포함되면 브러시로 고쳐 주세요.

곡선은 이미지 경계 방향을 계산한 표현이며 실제 타자기의 종이 회전 동작까지 재현하지는 않습니다.

설정을 바꾼 뒤 다시 그리면 적용됩니다. 밝은 배경과 또렷한 피사체가 있는 사진에 잘 어울립니다.

어떻게 그리나요?

사진을 흑백 명암으로 읽고, 작은 구역의 윤곽에 맞는 문자 획을 고릅니다. 짙은 구역은 여러 번 겹쳐 찍고 농도 오차를 이웃 구역으로 나눕니다. 모든 문자는 같은 잉크색과 불투명도로 찍습니다. 타건 밀도는 글자색이 아니라 문자 선택과 중첩량을 조절합니다.

사진의 실제 3차원 깊이나 사람의 의도를 이해하는 방식은 아닙니다. 밝기·경계·질감을 계산한 결과이므로 원본에 따라 표현이 달라집니다.

사용 권한이 있는 이미지를 선택해 주세요. 새로고침하면 현재 작업은 사라집니다.
