저작권·라이선스 고지

LETSUM(렛섬)은 상업용 무료 한글 폰트를 찾고 비교하도록 돕는 안내 서비스입니다. 폰트 저작권자와 배포처의 권리를 존중하며, 폰트를 소개하고 미리보기를 보여 줄 때 아래 원칙을 지킵니다.

공지일 2026-10-13

1. 폰트의 저작권

  • LETSUM에 소개된 모든 폰트의 저작권과 그 밖의 권리는 각 폰트의 저작권자에게 있습니다.
  • LETSUM은 폰트를 판매하거나 라이선스를 부여하지 않습니다. 폰트 이용 조건은 저작권자가 정한 원문 라이선스를 따릅니다.
  • LETSUM은 각 폰트의 저작권자·배포처와 제휴 관계가 없으며, 소개는 저작권자의 보증이나 후원을 뜻하지 않습니다.

2. 폰트 등록 원칙

  • 저작권자 또는 공식 배포처가 직접 공개한 라이선스 원문을 대조한 폰트만 등록하고, 근거 페이지와 확인일을 함께 기록합니다.
  • 원문을 끝까지 확인하지 못한 폰트는 '확인 중'으로 표시하거나 파일 없이 소개만 합니다.
  • 다른 폰트 큐레이션 서비스의 자료나 유료 폰트 판매처의 정보를 수집해 쓰지 않습니다.
  • 라이선스가 바뀌는지 주기적으로 다시 확인하고, 바뀌면 표시를 고칩니다.

3. 폰트 파일을 다루는 방식

  • 다운로드: 폰트 파일은 원칙적으로 저작권자·공식 배포처 페이지에서 받도록 연결합니다.
  • 미리보기 웹폰트: 배포처나 Google Fonts가 운영하는 공식 웹폰트 주소를 쓰거나, 라이선스가 재배포를 허용한 공식 파일을 글자 모양을 바꾸지 않고 사용합니다. 이때 라이선스 원문과 출처를 함께 둡니다.
  • 재배포가 금지된 폰트: 공개 저장소에 올리지 않고, 라이선스가 허용하는 웹사이트 표시 용도로 이 사이트 화면에서만 사용합니다. 파일 주소를 직접 열거나 다른 사이트에서 가져가는 요청은 차단합니다.
  • 보관 파일: 배포처 링크가 응답하지 않을 때를 대비한 보관 파일은 재배포가 허용된 오픈 폰트 라이선스(OFL) 폰트만, 원본 파일·라이선스 원문·출처를 그대로 묶어 제공합니다.
  • 폰트 파일을 수정하거나 줄인 파일(서브셋)을 만들어 배포하지 않습니다. 웹폰트 코드 만들기 도구는 이용자가 직접 받은 파일로 작업하는 방법만 안내하며, 수정이 허용된 라이선스에서만 그 방법을 보여 줍니다.

4. 미리보기 이미지와 적용 예시

폰트 카드·적용 예시·링크 미리보기 이미지는 각 폰트의 라이선스가 허용하는 웹 표시와 이미지 제작 범위 안에서 만든 소개용 이미지입니다.

5. 사용 범위 표시의 성격

  • 인쇄·웹·영상·임베딩·BI/CI 등 사용 범위 표시와 '라이선스 확인서'는 LETSUM이 원문을 확인한 시점의 내용을 정리한 참고 정보입니다.
  • 원문에 명시되지 않은 용도는 '조건부'로 표시하고 저작권자 확인을 권합니다.
  • 라이선스는 저작권자가 바꿀 수 있으므로, 실제로 쓰기 전에는 반드시 원문 라이선스를 확인해 주세요. 표시와 원문이 다르면 원문이 우선합니다.

6. 상표

폰트 이름, 회사·기관 이름과 로고는 각 소유자의 상표 또는 표장입니다. LETSUM은 폰트의 출처를 알려 주는 목적으로만 표시합니다.

7. 이용자 게시물

댓글과 사용 사례 사진의 저작권과 책임은 작성자에게 있습니다. 다른 사람의 권리를 침해하는 게시물은 신고나 요청을 받으면 숨기거나 삭제합니다.

8. 권리자 요청

저작권자·배포처께서 정보 수정, 미리보기 중단, 소개 삭제를 원하시면 아래 메일로 알려 주세요. 권리 확인 후 영업일 기준 3일 이내에 처리하며, 확인하는 동안에도 요청된 미리보기 파일은 먼저 내릴 수 있습니다.
