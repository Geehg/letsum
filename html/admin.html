연결 안 됨

관리자 키는 이 탭에만 기억되고, 탭을 닫으면 지워집니다. 사진·댓글·지표·테마 저장에 쓰입니다.

할 일

    운영 메모

    • 폰트 데이터·라이선스는 저장소(html/js/data.js)에서 관리합니다. 매주 월요일 자동 감시가 배포처 변화를 확인해 GitHub 이슈로 알립니다.
    • 히어로 색은 매주 제작사 소개 페이지에서 자동 추출되어 확인 전에도 바로 게시됩니다. '히어로 테마'에서 고치거나 끌 수 있습니다.
    • 사이트 파일이 바뀌면 NAS 패널에서 '받아와 재배포'를 눌러야 반영됩니다. 이 화면에서 저장하는 테마·사진·댓글은 서버에 바로 반영됩니다.

    왼쪽에서 폰트를 고르세요.

    방문자가 올린 사진은 여기서 승인해야 사이트에 보입니다. 거절하면 바로 삭제됩니다.

    읽기 전용입니다. 수정은 저장소의 data.js에서 하고 검증(tools/validate.py)을 거칩니다.
