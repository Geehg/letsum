라이선스 가이드

"무료 폰트"라도 폰트마다 쓸 수 있는 범위가 다릅니다. 다운로드 전에 이 페이지를 한 번만 읽어 두세요.

OFL(Open Font License)이란?

SIL 국제협회가 만든 오픈 폰트 라이선스입니다. OFL 폰트는 개인·상업 용도를 가리지 않고 자유롭게 사용할 수 있고, 수정·복제·재배포도 가능합니다. 단, 재배포할 때는 저작권·라이선스 고지를 함께 넣어야 하고, 수정본은 원래 이름 중 예약된 글꼴 이름(Reserved Font Name)을 쓸 수 없으며, 같은 OFL로 배포해야 합니다. 또 폰트 파일 자체만 따로 유료로 판매할 수는 없습니다. 자세한 조건은 OFL 원문을 확인하세요. 이 사이트의 폰트 상세 페이지에서 "OFL" 항목이 그 기준입니다.

용도별로 꼭 확인할 것

  • 인쇄 — 책·포스터·브로슈어 등 인쇄물 사용 가능 여부
  • 웹사이트 — 웹페이지·배너·메일 등에 글자로 쓰는 경우
  • 영상 — 유튜브·CF·자막·크레딧 사용 가능 여부
  • 임베딩 — 웹사이트 서버에 폰트 파일을 올려 웹폰트로 쓰거나, 전자책에 폰트를 넣는 경우 (일반 사용과 별도로 제한되는 폰트가 많습니다)
  • BI/CI — 로고·브랜드명에 쓰는 경우 (금지된 폰트가 꽤 있습니다)
  • 포장지 — 판매용 상품 패키지에 쓰는 경우
이 사이트의 검수 원칙
등록한 폰트는 저작권자가 공개한 라이선스 원문을 대조해 사용 범위 표를 작성합니다. 원문 대조를 마치지 못한 폰트는 ‘확인 중’으로 따로 표시하고, 각 폰트에 LETSUM이 마지막으로 확인한 날짜를 함께 적습니다. 배포처의 변화는 정기적으로 점검해 표에 반영합니다. 다만 표는 어디까지나 참고용이며, 최종 판단은 저작권자의 원문 라이선스로 해 주세요.

자주 묻는 질문

  • 상업용 무료면 회사 로고에 써도 되나요? — BI/CI 항목이 "사용 가능"인 폰트만 됩니다. 폰트마다 다르니 상세 페이지 표를 확인하세요.
  • 웹폰트로 제 홈페이지에 올려도 되나요? — 임베딩 항목이 허용된 폰트만 가능합니다. 이 사이트의 "웹폰트로 바로 쓰기"는 허용된 폰트에만 제공됩니다.
  • 폰트를 수정해서 써도 되나요? — OFL 폰트는 가능합니다. 다만 수정본은 예약된 글꼴 이름을 쓸 수 없고, 재배포할 때는 OFL 고지를 함께 넣어야 하며, 파일만 따로 팔 수는 없습니다. 그 외 라이선스는 원문 확인이 필요합니다.
  • 제가 만든 폰트를 등록하고 싶어요. — interq4@naver.com으로 배포 페이지와 라이선스 원문 주소를 보내 주세요.

받은 뒤 설치·적용하기

  • Windows — ZIP 압축을 풀고 .ttf/.otf 파일을 우클릭 → "모든 사용자용으로 설치". 여러 굵기 파일은 전부 설치합니다.
  • Mac — 파일을 더블클릭해 서체 관리자에서 설치합니다.
  • PPT·한글·포토샵에 안 보일 때 — 프로그램을 완전히 종료 후 다시 실행하세요. 목록에는 파일명이 아니라 글꼴 이름으로 뜹니다. .woff/.woff2는 웹 전용이라 설치되지 않습니다. 다른 PC에서 열 파일은 PPT "파일 > 옵션 > 저장 > 파일의 글꼴 포함"으로 저장하거나 PDF로 보내세요.
  • 아이폰·갤럭시 — iOS는 폰트 설치 앱으로 프로필을 설치해야 하고 앱 안에서만 쓸 수 있습니다. 갤럭시 시스템 글꼴은 Galaxy Store 글꼴만 적용됩니다.
  • 라이선스 확인서(PDF) — 각 폰트 상세의 "라이선스 확인서 (PDF)"로 사용 범위·라이선스 원문·출처·설치 후 이름·LETSUM 확인일을 A4 문서로 받습니다. 클라이언트·회사 제출용 근거로 쓸 수 있습니다(권리 보증은 아니며 최종 판단은 원문을 따릅니다).
  • 폰트 보관함 — 작업별 폴더로 폰트를 모으고 선택 이유를 메모해 두면, 폴더 속 폰트의 라이선스 확인서를 ZIP으로 한 번에 받거나 링크로 동료에게 넘길 수 있습니다. 담을 때의 사용 조건과 지금이 다르면 '조건 바뀜'으로 알려 드립니다. 즐겨찾기한 폰트도 조건이 바뀌면 다음 방문 때 알려 드립니다.

권리자 안내

등록된 폰트의 정보 수정·삭제가 필요하시면 문의 메일(interq4@naver.com)로 연락해 주세요. 본인 확인 후 영업일 기준 3일 이내에 처리합니다. 모든 폰트의 저작권은 각 저작권자에게 있으며, 다운로드는 원 배포처로 연결하며, 화면 미리보기에는 배포처 공식 웹폰트 주소나 재배포가 허용된 공식 파일만 글자 모양을 바꾸지 않고 씁니다. 재배포가 금지된 폰트는 공개 저장소에 올리지 않고 이 사이트의 화면 표시에만 사용합니다. LETSUM은 각 폰트의 저작권자·배포처와 제휴 관계가 없습니다.

LETSUM(렛섬) — 운영 고요서가 출판사 · 문의 interq4@naver.com · 모든 폰트의 저작권은 각 폰트의 저작권자에게 있습니다.
